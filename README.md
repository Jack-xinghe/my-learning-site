# 狐狐弹弓

最初代弹弓物理小游戏：拉开一只小狐狸，打掉藏在木石城堡里偷坚果的浣熊。

角色全部换成原创动物，避免鸟和猪的版权形象。

## 怎么玩

1. 用浏览器打开 `index.html`，或在本目录启动静态服务。
2. 选 **简单 · 林边小仓** 或 **中等 · 双塔仓库**。
3. 按住弹弓上的狐狸向后拉，松开发射。
4. 撞垮木头 / 冰块 / 石块，让浣熊被砸中或摔下去。

简单关 4 只狐狸、3 只浣熊；中等关 3 只狐狸、5 只浣熊，石块更耐撞。

物理用 [Matter.js](https://github.com/liabru/matter-js)（MIT），文件在 `vendor/matter.min.js`。

## 本地预览

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173`。
