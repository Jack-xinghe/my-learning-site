# 网页图片收集

Chrome 扩展（Manifest V3）。打开网页后可以识别页面里的图片，在页面上点选，再下载选中的图片或全部图片。页面滚动加载或脚本插入新图片时，列表会自动更新。

扩展代码在 `extension` 目录。

## 加载未打包的扩展

1. 打开 Chrome，地址栏输入 `chrome://extensions/`。
2. 打开右上角的「开发者模式」。
3. 点击「加载未打包的扩展程序」。
4. 选中本仓库里的 `extension` 文件夹（要选文件夹本身，不要选上一级）。
5. 工具栏出现「网页图片收集」。如果没看到图标，点拼图图标，把扩展固定到工具栏。

## 使用

1. 打开一个普通网页，点击扩展图标。弹窗会列出当前页识别到的图片，图标上也会显示数量。
2. 在弹窗里勾选图片，或打开「在页面上点选」。第一次打开弹窗时会进入点选模式。页面上的图片会出现边框：蓝色是未选，绿色是已选，再次点击取消。按 Esc 可退出点选。
3. 「下载选中」只保存勾选的图片；「下载全部」保存当前列表里的全部图片。文件在浏览器默认下载目录的 `网页图片/<网站域名>/` 下。
4. 页面后来才出现的图片会自动加入列表，不用刷新扩展，也不用重新打开弹窗。收起页面面板后，右下角的「图片」按钮可以再打开。
5. 关掉「点选模式」后，网页可以照常点击。整页背景图只出现在列表里，避免挡住整个页面。

## 能识别什么

- `<img>`，以及 `<picture>` / `srcset` 里浏览器当前会用的那一张
- CSS 背景图（含 `::before`、`::after`）和列表符号图片
- 常见懒加载地址，例如 `data-src`、`data-srcset`、`data-original`
- SVG `<image>`、视频封面、`input type="image"`
- 开放的 Shadow DOM，以及同源 iframe
- 脚本后来插入的图片（MutationObserver，弹窗打开时还会定时再扫一次）

## 限制

- 不能用在 `chrome://`、扩展商店等浏览器内部页面。
- 跨域图片会尽量下载。服务器如果校验防盗链、登录态或临时签名，下载可能失败，弹窗里也未必能预览。
- `blob:` 图片在页面里另存。一次保存多张时，浏览器可能会询问是否允许下载多个文件。
- 跨域 iframe 和封闭的 Shadow DOM 读不到。
- 盖住几乎整个视口的背景（例如 `body`）只进列表，不铺点击层。约 2px 的跟踪像素会被忽略。
- 同一个地址只列一次。`srcset` 在浏览器已经选定资源后，保存的是当前这张，不是无条件下载最大的候选图。标了 `data-original` 等原图属性时，优先用原图。
- 特别长的内嵌 data URL（约 300KB 以上）不会列入，以免把弹窗撑死。
- 网站图标（favicon）不在列表里。
